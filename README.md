# chases.dev

Developer portfolio site featuring latest GitHub activity and projects.

[![Deployed on Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black?style=for-the-badge&logo=vercel)](https://chases.dev)

## Overview

A Next.js-based portfolio site that displays:
- Personal introduction
- Latest GitHub repositories
- Recent commit activity

## Development

```bash
yarn install
yarn dev
```

Built with Next.js, React, TypeScript, and Tailwind CSS.
